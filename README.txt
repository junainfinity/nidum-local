Nidum Local: share what's running on this computer with your network.

macOS: double-click "Nidum Local.command". If macOS won't open it, go to System Settings >
Privacy & Security and click Open Anyway (older macOS: right-click it and choose Open).
The menu bar app (Nidum Local Menu) may need its own Open Anyway there too.
Windows (experimental): open launchers\windows and double-click "Nidum Local.cmd".
Linux (experimental): run launchers/linux/nidum-local.sh in a terminal.
It checks for Node.js 18+ and Portless, asks before installing anything, then opens
the dashboard in your browser. Logs are in ~/.nidum-local (launcher.log, server.log).
